# Kaue Natan Jungles

Bilingual portfolio for my web and full-stack work. It includes public projects, a reproducible WooCommerce case and links to the source behind each piece.

The live site is available at [devjungleskaue.github.io](https://devjungleskaue.github.io/).

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm test
npm run lint
npx tsc --noEmit
npm run build
npm run test:export
```
